## Text-to-Speech Project

## Description
This project implements a Text-to-Speech (TTS) system using Python. It provides a user-friendly interface built with Gradio, allowing users to input text and receive speech output. The goal is to demonstrate the capabilities of TTS technology in an interactive manner.
